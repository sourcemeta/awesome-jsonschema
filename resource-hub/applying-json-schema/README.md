# Applying JSON Schema

Resources showing how JSON Schema is used in APIs, applications, data systems,
configuration, and emerging technologies.

## APIs and Documentation

### Articles

- [Docs! Docs! Docs!](https://brandur.org/nanoglyphs/031-api-docs) - Describes producing API documentation from JSON Schema-based definitions.
- [In 76% of modern OpenAPI specs, JSON Schema dominates the specification](https://www.sourcemeta.com/blog/json-schema-dominates-openapi/) - An analysis of JSON Schema's share of modern OpenAPI documents.

### Videos

- [API Storytelling with Ben Hutton](https://www.youtube.com/watch?v=4xbA82lo_lc) - A conversation about vocabularies, validation, annotations, and APIs.

## Forms, Databases, and Configuration

### Articles

- [Building a No-Code JSON Schema Form Builder with ReactJS](https://www.ginkgobioworks.com/2020/10/08/building-a-no-code-json-schema-form-builder/) - Describes features of a React-based JSON Schema form builder.
- [JSON Schema Validation & Expressive Query Syntax in MongoDB 3.6](https://www.sitepoint.com/json-schema-validation-expressive-query-syntax-in-mongodb-3-6/) - Covers JSON Schema collection validation in MongoDB.
- [Azure Pipelines autocomplete in PyCharm, IntelliJ, WebStorm, CLion, and Rider](https://tonybaloney.github.io/posts/azure-pipelines-autocomplete-in-pycharm.html) - Uses a schema to enable editing support for pipeline configuration.

### Videos

- [Configuring Umbraco on .NET Core - JSON Schema](https://www.youtube.com/watch?v=rpUg-oySw8g) - Uses SchemaStore to provide completion for application configuration.

## Scientific Applications and AI

### Articles

- [Using the JSON Schema standard for scientific applications?](https://cerfacs.fr/coop/json-schema-for-sci-apps) - Applies validation, documentation, defaults, and generated interfaces to scientific inputs.
- [The only schema language AI speaks is JSON Schema](https://www.sourcemeta.com/blog/ai-only-speaks-json-schema/) - Surveys JSON Schema's use in structured AI outputs and tool interfaces.
