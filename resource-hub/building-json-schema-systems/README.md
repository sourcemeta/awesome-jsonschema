# Building JSON Schema Systems

Resources for engineers building schema infrastructure, large-scale tooling,
and production systems around JSON Schema.

## Schema Infrastructure

### Tools

- [Schema Gateway](https://github.com/sravan27/schema-gateway) - A gateway for managing and serving schemas.
- [schema-envoy](https://github.com/tamerkalla/schema-envoy) - A service for schema validation and distribution workflows.

### Books

- [Unifying Business, Data, and Code: Designing Data Products with JSON Schema](https://www.oreilly.com/library/view/unifying-business-data/9781098144999/) - Covers schema-driven data products and organizational systems.

## Operating at Scale

### Videos

- [Maintaining JSON Schemas at Scale - Jason Desrosiers](https://www.youtube.com/watch?v=GjJpRsVffg0) - Discusses patterns for maintaining a large collection of schemas.

### Articles

- [Project Cambria: Translate your data with lenses](https://www.inkandswitch.com/cambria/) - Explores bidirectional transformations for evolving data structures.
- [LLMs for Schema Augmentation](https://michael.mior.ca/blog/llms-for-schema-augmentation/) - Investigates using language models to augment inferred schemas.
