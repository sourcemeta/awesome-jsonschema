# Building Schemas

Resources for designing, composing, and maintaining clear JSON Schemas.

## Schema Design

### Articles

- [Modeling a file system with JSON Schema](https://json-schema.org/learn/file-system.html) - A worked example that models file-system mount points.
- [Understanding API Complexity Through Schema Entropy](https://smizell.com/posts/2021/05/understanding-api-complexity-through-schema-entropy/) - An approach to measuring API complexity through JSON Schema definitions.
- [Definitions for filtering properties in JSON schema](https://gist.github.com/LucianBuzzo/5ff9106ce3ae12fb58e4def572b9344d) - Discusses schema definitions for data filtering and querying.

### Courses

- [Master JSON Schema for OpenAPI](https://www.sourcemeta.com/courses/jsonschema-for-openapi/) - A course on schema design, composition, testing, linting, and deployment for OpenAPI.

### Books

- [API by Design](https://smizell.gumroad.com/l/apibydesign) - Introduces schema-based ways to reason about API complexity.

## Reuse and References

### Articles

- [Using Dynamic References to Support Generic Types](https://json-schema.org/blog/posts/dynamicref-and-generics) - Explains how dynamic references can model generic structures.
