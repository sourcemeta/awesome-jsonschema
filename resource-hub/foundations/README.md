# Foundations

Resources for learning the fundamentals of JSON Schema and developing a sound
mental model of how schemas work.

## Getting Started

### Tutorials

- [JSON Schema Tour](https://tour.json-schema.org) - An interactive,
  step-by-step introduction to JSON Schema.
- [Learn JSON Schema](https://www.learnjsonschema.com) - Documentation covering
  JSON Schema across specification versions.

### Articles

- [JSON Schema Validator, Generator & Editor Guide](https://stoplight.io/json-guide/) - An introduction to JSON and JSON Schema with practical examples.

### Videos

- [What is JSON Schema](https://www.youtube.com/watch?v=kK-_gL7Vsc0) - A basic introduction that includes generating a schema from JSON data.
- [What is a JSON Schema? Generate, Modify, and Understand a JSON Schema: Example](https://www.youtube.com/watch?v=hGXxXyJmaUo) - A worked introduction to generating and understanding schemas.

### Books

- [Using JSON Schema](https://books.apple.com/us/book/using-json-schema/id903248630) - Examples of applying JSON Schema with Node.js and Python.

## Core Concepts

### Articles

- [JSON Schema is a constraint system](https://modern-json-schema.com/json-schema-is-a-constraint-system) - Explains JSON Schema as constraints applied to JSON instances.

### Videos

- [So you think you understand JSON Schema? - Ben Hutton](https://www.youtube.com/watch?v=vMG0NCDifI0) - Examines common assumptions and subtleties in JSON Schema.
