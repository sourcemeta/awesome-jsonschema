# JSON Schema Ecosystem

Selected tools and registries for authoring, inspecting, transforming, and
publishing JSON Schemas.

## Authoring and Development Tools

### Tools

- [JSONBuddy](https://www.json-buddy.com) - An editor with JSON Schema authoring and validation support.
- [JSON Schema CLI](https://github.com/sourcemeta/jsonschema) - A command-line toolkit for JSON Schema workflows.
- [Sourcemeta Studio](https://github.com/sourcemeta/studio) - A web-based environment for working with JSON Schema.
- [AlterSchema](https://alterschema.sourcemeta.com) - A tool for translating schemas across schema languages.

## Registries

### Registries

- [Apicurio Registry](https://www.apicur.io/registry/) - A registry for schemas and API artifacts.
- [Sourcemeta One](https://one.sourcemeta.com) - A platform for managing JSON Schema projects.
- [Sourcemeta Schemas](https://schemas.sourcemeta.com) - A public registry of JSON Schemas.

## Integration Tools

### Tools

- [Context.dev Extract API](https://www.context.dev/data/extract) - An API for extracting structured data against JSON Schemas.
