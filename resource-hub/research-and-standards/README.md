# Research & Standards

Selected standards and research for readers studying JSON Schema's formal
foundations, implementations, and relationships with other technologies.

## Related Standards

### Specifications

- [OpenAPI](https://www.openapis.org) - An API description standard that embeds and extends JSON Schema.
- [AsyncAPI](https://www.asyncapi.com) - An event-driven API specification that uses JSON Schema for data models.
- [W3C Web of Things](https://www.w3.org/WoT/) - W3C standards for connected-device descriptions that use JSON Schema data models.
- [Semantic Definition Format (SDF)](https://datatracker.ietf.org/doc/draft-ietf-asdf-sdf/) - An IETF specification for modeling IoT devices that incorporates JSON Schema.
- [JSON Schema in RDF](https://www.w3.org/2019/wot/json-schema) - An RDF vocabulary for JSON Schema keywords and definitions.

## Formal Foundations and Validation

### Papers

- [Foundations of JSON Schema](https://dl.acm.org/doi/abs/10.1145/2872427.2883029) - A formal account of JSON Schema syntax and semantics.
- [Validation of Modern JSON Schema: Formalization and Complexity](https://arxiv.org/abs/2307.10034) - Formalizes modern validation and studies its computational complexity.
- [Type Safety with JSON Subschema](https://arxiv.org/abs/1911.12651) - Presents an approach for deciding schema containment through canonical forms.
- [Witness Generation for JSON Schema](https://arxiv.org/abs/2202.12849) - Studies generating instances as a basis for satisfiability, inclusion, and equivalence analysis.
- [Elimination of annotation dependencies in validation for Modern JSON Schema](https://arxiv.org/abs/2503.11288) - Examines annotation dependencies in modern JSON Schema validation.

## Schemas in Practice

### Papers

- [What Are Real JSON Schemas Like?](https://link.springer.com/chapter/10.1007/978-3-030-34146-6_9) - An empirical analysis of real-world JSON Schemas.
- [An Analysis of Defects in Public JSON Schemas](https://www.cri.minesparis.psl.eu/classement/doc/A-794.pdf) - Studies defects found in publicly available schemas.
- [JSONoid: Monoid-based Enrichment for Configurable and Scalable Data-Driven Schema Discovery](https://arxiv.org/abs/2307.03113) - Presents configurable, scalable schema discovery for JSON data.
- [Blaze: Compiling JSON Schema for 10x Faster Validation](https://arxiv.org/abs/2503.02770) - Investigates compilation techniques for high-performance validation.
