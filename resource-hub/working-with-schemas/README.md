# Working With Schemas

Resources for validating, testing, evolving, and maintaining schemas after they
have been created.

## Validation and Testing

### Articles

- [Saved by the Schema: Using JSON Schema to Document, Test, and Debug APIs](https://blog.heroku.com/json-schema-document-debug-apis) - Describes using schemas to test and document an API and diagnose a production issue.

### Videos

- [JSON Schema Validation in Postman](https://www.youtube.com/watch?v=8BfshV5n6ac) - Demonstrates JSON Schema validation in Postman API tests.
- [JSON Schema Validation: How to Validate JSON Schema with Postman?](https://www.youtube.com/watch?v=X072eKtOIio) - Introduces validating API responses with JSON Schema in Postman.

## Bundling and Distribution

### Articles

- [JSON Schema bundling finally formalised](https://json-schema.org/blog/posts/bundling-json-schema-compound-documents) - Explains bundling and dereferencing compound schema documents.

## Evolution and Compatibility

### Articles

- [Understanding JSON Schema compatibility](https://yokota.blog/2021/03/29/understanding-json-schema-compatibility/) - Explores compatibility relationships between schemas.
- [Introducing SchemaVer for semantic versioning of schemas](https://snowplowanalytics.com/blog/2014/05/13/introducing-schemaver-for-semantic-versioning-of-schemas/#feedback) - Presents a versioning convention for schemas.
- [Robustness, Tolerance, and JSON Schema](https://smizell.com/posts/2021/07/robustness-tolerance-and-json-schema/) - Discusses compatibility and tolerant change in schema-governed APIs.
